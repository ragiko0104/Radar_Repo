# 尾部散射点自旋识别（1 kHz PRF）

更新：2026-10-21。本文对应 `identify_isar_spin_from_tail_points`：在 PRF 固定 1 kHz 的前提下，把 `P2–P4` 三个底部散射点纳入观测量，识别锥尖轨迹无法给出的自旋频率 `fs`，并测试多普勒折叠（混叠）还能否识别。前置的锥尖微动识别见 [锥尖轨迹盲微动模式识别](ISAR_TIP_MODE_IDENTIFICATION.md)。

## 1. 2026-10-21 历史实验

本节保留早期搜索范围下的结果。目前的检出条件见 §5；当前模拟数据的独立种子复测见 [灵敏度窗口](ISAR_SENSITIVITY_LIMITS.md)。

| S1 fs1 fp1 α3° | 1 Hz | 0.55× | 1.0000 | −0.0002 Hz | 检出 |
| S2 fs1 fp1 α1° | 1 Hz | 0.53× | 0.9995 | −0.0005 Hz | 检出 |

- **优先场景（1 Hz 自旋 + 1 Hz 进动）不折叠**：根部最大多普勒 276 Hz，只有 ±500 Hz 区间的 0.55 倍，自旋误差 2e-4 Hz。
- **折叠后仍能识别（仅限仿真）**：三个折叠场景（1.12×、1.59×、1.99×）的 `fs` 在运动学仿真中都复原到 1e-3 Hz 以内，目标函数扫描只有一个极小值。**真实链路复核推翻了这一条**：1.59× 折叠的真实提取轨迹无法复原 `fs`，原因见 §9。
- **无自旋场景被正确拒绝**，`fs` 估计为 0 而不是被硬套一个正频率。
- 自旋频率 RMS 误差 0.0003 Hz，最大误差 0.0005 Hz，判决 6/6 正确。

## 2. 为什么尾点能看到自旋

锥尖 `P1 = (0,−0.75,0)` 在自旋轴上，`Ry(2π fs t)` 对它恒等，所以锥尖轨迹与 `fs` 严格无关。三个底面点 `P2–P4` 在 `y = +0.75 m`、半径 0.3 m 的圆上，自旋会让它们绕轴转圈，LOS 投影按 `fs` 振荡，并同时受到进动 `fp` 的调制，出现 `fs`、`fp`、`fs±fp` 等交叉项。

`test_isar_cone_point_kinematics` 把这条边界钉死：尖端距离/距离率在 `fs = 0/1/3.5 Hz` 下逐点相同（<1e-12），而 `P2` 对同样的 `fs` 变化反应超过 100 Hz。

## 3. 多普勒预算与折叠判据

在 α 较小时，根部点的距离投影为

```
R_k(t) ≈ [0.75 − 0.3·cos(2π f_s t − φ_k)] / √2 · cos(2π f_p t) + 常数
```

`cos(2πf_s t)·cos(2πf_p t)` 把它展开成 **`f_s ± f_p`** 两个主分量，每个分量的多普勒幅度约 `131.5·(f_s+f_p)` Hz，其中 `131.5 = (2/λ)·(0.3/√2)·2π`。这也解释了为什么“1 Hz 自旋不混叠”还依赖进动：幅度按 `f_s+f_p` 增长，不是只看 `f_s`。数值上 `131.5·(f_s+f_p)` 与仿真最大多普勒吻合到百分之几（fs3/fp3 预测 789 Hz、实测 793 Hz；fs3.5/fp3.5 预测 920 Hz、实测 995 Hz，余量来自 α=7° 与摆动）。

| 场景 | 根部最大 \|多普勒\| | 与 ±500 Hz 之比 |
|---|---:|---:|
| S1 fs1 fp1 α3° | 276 Hz | 0.55× |
| S2 fs1 fp1 α1° | 266 Hz | 0.53× |
| S3 fs1 fp3 α3° | 562 Hz | 1.12× |
| S4 fs3 fp3 α3° | 793 Hz | 1.59× |
| S5 fs3.5 fp3.5 α7° A5° | 995 Hz | 1.99× |

注意即使 `fs = 1 Hz`，只要进动到 3 Hz、半锥角 3°，根部就已经越界（562 Hz）。也就是说"1 Hz 自旋不混叠"只在进动较低时成立，这一点比直觉更严格。锥尖侧始终不超过 171 Hz，所以进动/章动参数在任何场景下都不受折叠影响——这是两级估计可行的前提。

## 4. 测量算子

观测量不是瞬时多普勒，而是每个 CPI 的 32 脉冲相干驻留谱峰：对散射体相位 `4πR/λ` 在驻留内采样，做零填充 FFT，再用对数抛物线插值取峰。这个算子天然是周期的，所以根部多普勒超出 ±PRF/2 时会**自动折叠**，不需要额外的人工 `mod` 建模——折叠是采样本身的性质。

估计器用的正是同一个算子（`isar_predict_cone_peaks`），而不是"驻留平均后取模"的近似。两者差别可观：在 280 Hz 的多普勒摆幅下，32 ms 驻留内瞬时值变化约 56 Hz，谱峰与驻留均值相差约 1.3 Hz，直接决定残差水平。补零倍数必须与数据生成一致；早期版本预测器用 128、仿真用 2048，折叠场景残差被抬高到 3–6 Hz，统一到 512 后降到 0.09 Hz。

## 5. 估计方法

第一级以锥尖四假设阶梯取得进动与摆动参数。第二级在四轨上精修 `[fs, ψs, α, ψp]`，每轨独立消去截距和斜率。`fs` 网格步长为 0.05 Hz，搜索上界按主分量近似取 `max(0,min(5,3.80−fp))`。

判决用**嵌套假设检验**：把 `fs` 钉在 0 重新拟合并得到 `RSS₀`，与自由拟合的 `RSS₁` 比较

```
F = (RSS₀ − RSS₁) / (RSS₁ / (N − 12)),   N = 4 轨 × 50 CPI = 200
```

名义自由度差为 1；完整模型有 4 个非线性参数和 8 个逐轨仿射系数，残差自由度为 188。经验检出条件为 `F > 10`、`fs > 0.2 Hz`、联合 RMS < 10 Hz。仿真真值诊断 `aliased` 与 `spinDetected` 可同时为真。

### 一条必须记录的弯路

第一版把 `fs` 的搜索下界设为 0.2 Hz，结果 S6（`fs = 0`）被解成 **4.95 Hz**、联合残差 274 Hz。原因是模型库根本表达不了"无自旋"，优化器只能在正频率区间里找最不像话的折中。**能表达零的假设是识别的前提，不是可选项**——这与锥尖分析里"未激活参数必须置零"是同一类错误。修正后 `fs = 0.000`，且嵌套检验给出 `F ≈ 0`。

## 7. 边界

- **这批数据是运动学仿真，不是 RF 链路输出**。散射体坐标、姿态链、多普勒预算都已对 `scatterermodel` 核对（距离 2.6e-5 m、速度 1.5e-4 m/s），测量算子也与 `run_isar_tip_slowtime_tracks` 的提取方式一致，但没有经过 1 GHz 内部网格的宽带合成、去斜、色散补偿与距离门。要确认端到端，需要把 `run_isar_tip_slowtime_tracks` 扩成四通道逐点提取后重跑。
- **假设了理想的点分离与门选取**。真实系统需要用检测/跟踪把四个点分到各自的距离门，`P2–P4` 与锥尖的最小间距 0.57–0.83 m（见交接文档）是够的，但关联错误会直接污染自旋估计。
- **`fs = fp` 时的可分性**：S1/S2 的可分性来自四点几何与相位约束，而不是频率分离。当前结果说明在无噪与 0.1 Hz 噪声下可分，但没有系统扫描 `fs` 与 `fp` 接近时的条件数。
- **折叠仍可能制造伪解**：本文 6 个场景在 `[0,5] Hz` 内都没有竞争极小值，但这是场景相关的结论，不是普适保证。更高转速需要靠"多谐波折叠模式一致性"来排除伪解，本文只是观察到它有效。

## 9. 真实链路复核（2026-10-21 补充）

§1–§7 用的是运动学仿真。把 `run_isar_tip_slowtime_tracks` 扩成四通道逐点提取（`run_isar_multi_point_tracks`）后，三个场景跑了完整 RF 链路：库按 1 GHz 网格合成宽带 LFM、去斜、原 ISARpath 前端、每 CPI 固定本振、分数对齐、CA 先验相位、逐点距离门、慢时间 FFT。每场景 50 CPI，8 进程约 2 分钟。

|---|---:|---:|---:|---:|---:|---|

### 有效结论

- **不折叠的优先场景在真实链路上成立**：2/2 正确，`fs` 误差 2–3e-4 Hz，F 检验 9e4–1.3e5。
- **折叠场景在真实链路上不成立**：1.59× 折叠时估计器退化为 `fs≈0`，联合残差 219 Hz。仿真里"2× 折叠仍能复原"的结论不能外推。

### 为什么

1. **每个散射点有独立的冗余偏置。** 锥尖拟合出的 `c0 = +5.18 Hz` 不能被根部点共用：实测根部点的偏置是 −6.5/−4.0/−4.4 Hz（α=3°）和 −8.4/−3.0/−4.5 Hz（α=1°）。这符合 RVP 距离耦合项的预期——偏置正比于散射点自身的距离偏移，几个根部点相距近 1 m，偏差就有这个量级。估计器已改为逐点最小二乘拟合 `[1, t−t̄]`（`rssAt` 里对每条轨先"按最贴近模型的分支展开"再投影），这一项把联合残差从 11.8 Hz 降到 7.9 Hz。
2. **剩余 7–8 Hz 是测谱算子的形状误差，不是偏置。** 根部的多普勒摆幅是 276 Hz，32 ms 驻留内扫过约 55 Hz，谱峰本来就宽；真实链路还要对 3 个距离 bin 求和并受距离窗加权，而模型只对单点相位做 FFT。锥尖在同一时刻只差 0.003–0.5 Hz，因为它的摆幅只有 17 Hz。也就是说误差随摆幅线性增长，约 3%。
3. **折叠场景把这个形状误差放大成灾难。** 真实的根部峰值反复跳在 ±490 Hz（贴住 ±500 Hz 边界），峰值位置由窗和泄漏决定，模型给出的折后值与实测对不上，最小二乘在剖面化之后仍然只能落到 `fs≈0`，残差 219 Hz。

### 后续要做什么

- 把观测量从"单个谱峰"换成"每点距离门内的完整慢时间谱"（或直接对相位做匹配），这样形状误差变成可拟合的量，而不是被 argmax 压缩掉的信息。
- 或者提高每 CPI 的采样：多普勒模糊来自 1 kHz PRF，若不改 PRF，只能靠更多点/更长驻留换取信噪比。
- 折叠边界附近应显式检测（当前有 `foldCount` 指标），并对该类 CPI 降权，而不是让边界样本主导最小二乘。
