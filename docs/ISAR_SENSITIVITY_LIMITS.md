# 微动识别灵敏度窗口

## 当前实现及复测（2026-11-22）

锥尖识别使用 H0–H3 四项 F 阶梯。阈值 10 取自实验。v13 引入 F4，v14 增加 N≥18 的降级条件。本次修订保留该判决，修正 H1 相位边界、锥尖折叠算子、自旋自由度和噪声种子。§1–§12 按版本保留历史数据。

- **锥尖相位**：0.5 Hz、5 s、噪声标准差 0.2 Hz。3°、5°、6°、8°、20° 各取五个初相，每点两份独立噪声，50/50 选 H1。最大绝对误差为 0.000934 Hz 和 0.0391°。可用 `sweep_isar_tip_phase(outputDirectory)` 重放，CSV 保存每次的种子、初相和误差。
- **角度重叠**：3–8° 与 5–20° 在 5–8° 内都相容。6°、同相位和同噪声时，0.8 Hz 和 3 Hz 轴向自旋产生逐点相同的锥尖轨迹；边界需结合角度估计误差解释。横轴翻滚需要另一种运动模型。
- **历史轨迹复核**：14 个已有提取场景均能从正式入口产生结果。默认门限下完整模式判对 9/14，5 个纯进动场景被报为复合，和 499bc53 的底层识别结果逐例一致。
- **自旋独立复测**：`sweep_isar_micro_motion_limits(struct('SpinOnly',true,'OutputDirectory',outDir))` 生成 85 行、85 个可重放种子。固定 fp=1.7 Hz、α=3°、每轨噪声 1 Hz，fs 主扫描在 0.3、0.5、1、2 Hz 各通过 5/5；0.2 Hz 通过 3/5；0.05、0.1、3、4、5.5 Hz 均为 0/5。耦合扫描中 1、1.4、1.6、1.7、1.8 Hz 各为 5/5，2.2、3.4 Hz 为 0/5。完整模型在四条 50 帧轨迹上的名义残差自由度为 188。
- **折叠**：锥尖在 32 ms 内取八个中点平均，叠加偏置后折叠至 ±PRF/2 的半开区间，残差按同一周期取主值。该处理定义了观测与残差；折叠条件下的全局盲反演没有唯一性保证。四轨自旋的搜索上界是近似约束。合成场景 fs=2 Hz、fp=1.7 Hz、α=12° 的折叠倍数为 1.19，仍通过自旋判决。
- **分辨率**：历史扰动实验以固定 H3、五次误差均小于半步为通过条件，fp 和 α 的最小通过步长为 1 mHz、0.03°。演示稿另列成功样本 RMS 误差，两种量的评分定义不同。
- **大摆幅**：上界实验存档中 A=14/18/21/25° 的通过数为 0/5、5/5、0/5、1/5，随幅度呈非单调变化。fw≈fp 时接口仍会给出普通标签和拟合量。

## 2. 每一条边界的性质不同

这是本文最重要的结论：**五个下界/上界由五种不同机制决定**，不能用一个"灵敏度"概括。

### `fp`：真正的分辨率极限
`fp=0.2 Hz` 在 5 s 内正好一个周期，拟合失败（估计 0.35 Hz）；`0.3 Hz`（1.5 周期）恢复。边界与 `1/T = 0.2 Hz` 一致，是**慢时间孔径**决定的物理极限。上界 5 Hz 是 10 Hz 采样率的奈奎斯特，与算法无关。

### `α`：误判，而非噪声不足
`α ≤ 0.1°` 时估计值不是"接近 0"，而是**跳到 2.6–4.9°**——拟合把残余结构解释成了一个更大的进动（并伴随 4.7° 的假摆动）。这是**模式混淆/假阳性**，比单纯估不准更危险：算法会自信地报出一个大角度。

用解析量核对：`α=0.1°、fp=1.7` 时锥尖多普勒幅度 `329·sinα·fp = 0.98 Hz`，是噪声（0.2 Hz）的 5 倍，**信息是够的**。所以 0.5° 这个下界是算法（结构选择 + 局部优化）造成的，不是可观测性造成的。

### `A`：门限乐观 + 种子固定
标称判决门限是 0.2°，但 `A=0.2°` 实测 P=0（5 次里估计值 0.04–0.2），`0.3°` P=0.6，`0.5°` 才 P=1。**实际可靠下界比标称门限高约 2.5 倍**。上界不是物理的：种子把 A 固定在 3°，`A=6°` 时优化落进局部极小（估计 2.9°），而 `A=10°` 又恢复到 P=0.8 且有一次跳到 21.4°——典型的非单调优化地形。

### `fw`：种子覆盖不足（v3 已修复）
`fw=3 Hz` 失败（估计 1.63 Hz），不是因为它超出可观测范围（3 Hz 在 5 s 内有 15 个周期，分辨率绰绰有余），而是 `seedsComposite` 的摆动频率网格只到 **2.4 Hz**，Nelder–Mead 从 2.4 出发滑进了 `fw≈fp` 退化谷。v3 把网格扩到 4.8 Hz 后该点恢复（5/5，估计 3.000），详见 §10。

### `fs`：判决门限，而非统计量
`fs=0.05 Hz` 时 F 统计量高达 **8.6e5**，估计值 0.051 Hz 也准，但冻结规则要求 `fs>0.2 Hz`，于是判为"无自旋"。**下界是规则写死的，不是数据看不出来**。上界是折叠：`fs=4`（1.49×）仍 P=1，`fs=5.5`（1.82×）崩掉（返回 0.012 Hz、残差 203 Hz）。

## 3. 微动之间的耦合

### 3.1 `fw = fp`：唯一的硬退化
`fw` 从 `fp-0.1` 扫到 `fp+0.1`：`1.6/1.8 Hz` 全部 P=1，**只有 `fw=fp=1.7` 这一个点 P=0**（估计 fw 1.55、A 1.31、fp 1.55）。原因是摆动下边带落在 `fp−fw=0`，与常数项 `c0` 完全简并，上边带落到 `2fp`。退化宽度约 ±0.1 Hz（即一个慢时间分辨单元），之后立刻恢复。

这意味着：**当真值与 `fw≈fp` 重合时，摆动参数不可辨识，而算法不会报告异常**——它只是给出一个错误的、看起来合理的解。

### 3.2 `fs ≈ fp`：不耦合
`fs` 从 1.0 扫到 3.4（含 `fs=fp=1.7`）：**全部 P=1，误差 <0.1%**。虽然根部多普勒主分量是 `fs±fp`，`fs=fp` 时下边带落到 DC、上边带落到 `2fp`，但三个根部点的**相位关系**（相隔 120°）把它们分开了。这是四点几何带来的冗余，不是频率可分辨性。

### 3.3 `α` 与 `A`：弱信号时会互相顶替
`α ≤ 0.1°` 时算法报出 `α≈4.7°` 且 `A≈4.7°`——两者同时被"借"去解释本应属于进动的调制。也就是说小半锥角会被误判成"大进动 + 大摆动"。耦合方向是单向的：大 `α` 不会伪装成 `A`（`α=3°` 时 A 稳定在 0.02°）。

### 3.4 `A` 与 `fw`
两者的乘积决定边带幅度（`5.71·A·fw` Hz）。`A=10°` 与 `A=3°` 在同一 `fw` 下的边带幅度差 3 倍，算法都能分开；没有观察到 `A·fw` 的恒定幅度简并。

## 4. 与成像分辨率的关系

结论：**在本题参数下，成像分辨率不是限制因素**，限制因素是慢时间孔径与判决逻辑。

| 分辨率 | 数值 | 是否限制 |
|---|---|---|
| 距离分辨率 `c/2B`（B=6 GHz） | 0.025 m | 否。四点最小间距 0.57–0.83 m，约 23–33 个分辨单元 |
| 单 CPI 多普勒分辨率 `PRF/32` | 31.25 Hz | 否。峰值用对数抛物线插值，50 个 CPI 平均后等效噪声 0.2 Hz |
| 慢时间分辨率 `1/T`（T=5 s） | 0.2 Hz | **是**。直接决定 `fp≥0.3 Hz`、`fw≥0.5 Hz` |
| 无模糊多普勒窗口 `±PRF/2` | ±500 Hz | **是**。直接决定 `fp<5 Hz` 与 `fs` 的折叠上界 |

也就是说，提高带宽或距离分辨率对这几个边界没有帮助；要改善下界只能拉长观测时间（`T`），要改善上界只能改 PRF 或换观测量。

一个可算的判据：`α` 的可靠下界满足 `329·sinα·fp ≳ 5·σ`；`σ=0.2 Hz`、`fp=1.7` 时给出 `α ≳ 0.1°`。**解析预测 0.1°，实测 0.5°**，差距正是第 2 节说的"算法而非信息"造成的。

## 5. 边界

- 全部扫描用的是冻结观测算子的**运动学仿真**（`peakFftPoints=512`），不是真链路（真链路是 2048）。真链路的根部点有 7–8 Hz 系统残差，`fs` 的上界会明显收缩：实测 **1.59× 折叠（fs=3, fp=3）已经失败**，而仿真到 1.49× 仍成功。所以 `fs` 上界在真链路上应取 **≤1.3× 折叠**（`fs+fp ≲ 3.8 Hz`）。
- 每点只有 5 次实现，P 的分辨率是 0.2；边界位置有 ±1 个格点的误差。
- 孔径扫描被污染：该组用 `α=1°`（本身 P=0.8），四个孔径都出现同一例失败，无法分离孔径效应。`1/T` 的结论是从 `fp` 扫描得到的。
- `fw>2.4 Hz`、`A≥6°` 的失败是种子/优化造成，换种子即可改变，不代表信息极限。

## 6. 若要提高灵敏度（本次不做，仅记录）

1. 拉长观测时间：`fp` 下界与 `1/T` 成正比，10 s 可把 0.3 Hz 降到 0.15 Hz。
2. 修 `fw` 种子网格上限（2.4 → 4.9 Hz）和 `A` 种子（增加 6°、10°），可立刻扩展两个上界。
3. `fs` 的 0.2 Hz 门限是人为的，F 统计量在 0.05 Hz 时仍为 8.6e5，可以按显著性而非固定门限判决。
4. `fw=fp` 的退化只能靠先验或第二段观测打破。

## 10. v2 / v3：只针对 fw 上界的定向修复

v1 的诊断指出 `fw=3 Hz` 失败是种子覆盖不足，不是物理极限。按此做了两版修改，全部只动种子，不动判决规则、不动观测算子。

### 10.1 改了什么

| 版本 | 改动 | 结果 |
|---|---|---|
| v1 | 基线：`fw` 种子网格 0.40:0.20:2.40，`A` 种子固定 3° | `fw=3` 失败（P=0） |
| v2 | `fw` 网格扩到 4.80；`A` 种子 2/5/10°；精修名额 12→24；按 (fp,fw,α) 分组各取 12 个盆地 | `fw=3` 修复；但 `A=3` 由 1.00 掉到 0.40、`fw=0.7` 由 1.00 掉到 0.00 |
| **v3** | 只保留 `fw` 扩展（4.80 Hz），`A` 种子回到 3°；仍然两组各取 12 个盆地 | **`fw=3` = 1.00，其余与 v1 逐位相同** |

### 10.2 v3 与 v1 的逐点差异（同一噪声序列）

| 扫描 | 取值 | v1 | v3 | 说明 |
|---|---|---:|---:|---|
| `fw` | 3.0 Hz | 0.00 | **1.00** | 目标修复，5/5，估计 3.000 Hz、rms 0.18 |
| `fw` | 5.0 Hz | 0.00 | 0.20 | 参数上界是 4.9 Hz，5 Hz 本来就在可搜索范围外，属于偶然落入容差 |
| `fp` | 5.0 Hz | 0.00 | 0.20 | 同上，5 Hz 贴着奈奎斯特，不是真实改善 |

其余 40 个扫描点（`fp` 0.05–7、`alpha` 0.03–12、`A` 0.02–10、`fw` 0.05–2、四个孔径、七个 `fw≈fp` 耦合点）与 v1 **完全相同**，自旋扫描也完全不变（`fs` 0.2–4）。

窗口变化只有一处：`fw` 由 0.5–2.0 扩展到 **0.5–3.0（实测）**，实际上界由参数上界 4.9 Hz / 奈奎斯特 5 Hz 决定。

### 10.3 `A` 种子扩展：试了，但撤回

`A` 从"固定 3°"改成 2/5/10° 三级后：

- `A=10°` 的成功率由 0.80 升到 **1.00**（估计 10.03°）；
- 但 `A=3°` 由 1.00 掉到 **0.40**，`fw=0.7 Hz`（同一组参数）由 1.00 掉到 **0.00**，`A=6°` 仍是 0。

`A=6°` 没有修好，而 `A=3°` 反而退化，净收益为负，所以 v3 撤回了这一项。留待后续：`A≥6°` 的失败不是种子覆盖问题（种子 5° 和 10° 已经包住 6°），而是大摆幅下目标函数本身的局部极小，需要别的办法（例如按 `A` 分段精修或加正则）。

### 10.4 一条实现层的教训：种子不能只加不分组

v2a（只扩种子、精修名额仍 12 个）与 v2b（名额加到 24）的结果**逐位相同且都变差**。原因是 1800 个种子按"原始残差"排序时，偶然相位匹配的坏盆地会把真盆地挤出榜单——种子越多，被挤出得越容易。

v2c 起改成**分组选种**：第 1 组是 v1 的种子集（`fw≤2.4`），第 2 组是扩展集（`fw>2.4`），各自按原始残差取 12 个互不相同的盆地再精修。这样"原有行为"由第 1 组保证，"新增覆盖"由第 2 组提供，两者互不挤出。v3 的逐位一致（除目标点外）正是这个分组带来的。

### 10.5 仍未解决

- `fw=5 Hz`：超出 4.9 Hz 的搜索上界，要覆盖需同时放宽上界，与 5 Hz 奈奎斯特冲突。
- `A=6°`：大摆幅的局部极小，见 10.3。
- `fw=fp` 退化（P=0）与 `α≈0.1°` 的假阳性：两者都是 α–A 互换性造成的，种子改动无效，需要判决层的约束或第二段观测。

### 10.6 试过但否掉的方案：相位解析种子

§10.4 指出排序被相位错配主导，最自然的修法是**把相位解析消掉**：对每个 `(fp,fw)` 格点解一个六列线性最小二乘，直接得到四个音调系数，再换算成幅度与相位——

```
f(t) ≈ a_s·sin(2π fp t) + a_c·cos(2π fp t)
     + b_s·sin(2π fw t) + b_c·cos(2π fw t) + c0 + c1·(t−t̄)

sinα = √(a_s²+a_c²)/(scale·fp·sinc(fp·T))      ψp = atan2(a_c, a_s)
A    = √(b_s²+b_c²)/(scale·fw·sinc(fw·T))      ψw = atan2(b_c, b_s)
```

这样每个种子自带接近最优的相位，**并且**线性残差对相位不变，理论上可以直接用它排序、去掉分组。实测两种用法都失败：

| 用法 | 结果 |
|---|---|
| 线性残差排序 | 所有解塌到 `fw ≈ fp`。`fw→fp` 时四个音调列近似共线，自由度被人为放大，线性残差对退化格点系统性偏低 |
| 线性解定种子 + 非线性排序 | `A=3°/fw=3.0` 五次全错（估计 A=0.27、fw=2.19、rms 20）；`A=3°/fw=1.6` 五次全错。线性近似在大摆幅下给出的 α、A 偏差反而把种子推离真盆地 |

唯一的正面副作用是 `α=0.1°` 的假阳性消失了（估计 A≈0.01°），但这不足以抵消其余全面退化。**结论：v3 的分组选种保持不变**；若要继续这条路，更可行的是"每个种子先跑 60–100 次 NM 再排序"（直接度量盆地质量，约 0.8 s/次拟合），本次未验证。

### 10.7 试过但否掉的方案二：按"短精修后的残差"排序

§10.6 的结论指向第三条路：不解相位，而是**让每个种子先跑一小段 NM，再按收敛后的残差排序**。这样排序度量的是种子真正所属的盆地，理论上可以只排一次、去掉分组。

实现时有一步是必需的：`fminsearch` 的初始单纯形取"参数值的 5%"，而相位种子是 0，步长只有 2.5e-4 rad，50 次评估内根本挪不动相位。所以另写了带显式单纯形的 `nmSearch`（相位步长 1.2 rad），短排序才有效。

结果（同一噪声序列，与 v3 逐点对比）：

| 扫描 | 取值 | v3 | v6 | 判读 |
|---|---|---:|---:|---|
| `A` | 0.2° | 0.0 | 0.6 | 改善 |
| `A` | 0.3° | 0.6 | 1.0 | 改善 |
| `A` | 6° | 0.0 | **1.0** | 修复 |
| `A` | 10° | 0.8 | **1.0** | 修复 |
| `alpha` | 0.05° | 0.0 | 0.6 | 改善 |
| `alpha` | 0.1° | 0.0 | 0.6 | 改善 |
| `alpha` | 0.5° | 1.0 | **0.0** | 退化 |
| `alpha` | 1° | 0.8 | 0.4 | 退化 |
| `A` | 0.5° | 1.0 | **0.0** | 退化 |

窗口：`A` 由 0.5–3 扩展到 **0.3–10**，但 `alpha` 由 0.5–12 收缩到 **3–12**。速度反而更快（1.22 s/拟合 vs ~2 s）。

**失败原因不是优化器，而是模型本身有退化。** 退化解的形态是 `alpha≈0.004, A≈0.998, fsw≈fp`，核对公式

```
A = (328.7/5.71)·sin(alpha) = 57.6·sin(alpha)
alpha = 0.5° → A = 0.503   实测 0.500
alpha = 1.0° → A = 1.005   实测 0.998
```

而两种解的残差只差第 5 位有效数字（0.15235 vs 0.15216）。也就是说 `fsw = fp` 时"用摆动冒充进动"是与真解**等价的另一个解**。正因为如此，**更强的盆地搜索会更频繁地落到它上面，而不是更少**。

试过加 Occam 平票规则（残差在最优 2% 内的解里取摆幅最小者）：`alpha=0.3°` 恢复 4/4，但 `alpha=0.5°` 仍是 0/4——因为正确盆地根本没被找到，平票规则只能在已找到的解里挑。

**结论**：第三条路在"去掉分组选种"和"扩展 `A` 上界"上成立，但代价是 `alpha` 下界从 0.5° 退到 3°。本项目的物理场景集中在 `alpha = 1–7°`，这个代价不可接受，因此**保留 v3**。若要同时拿到两边，必须**打断退化**，例如同时拟合 H1 与 H3，当 `RSS_H1` 与 `RSS_H3` 在容差内相等时按简约原则选 H1（等价于判 `A = 0`）。这条本次未实现。

## 11. H1/H3 简约判决（v10）

§10.7 的结论是：互换孪生解是模型本身的性质，改搜索只会让它更容易被找到。所以修法必须落在**结构判决层**。

### 11.1 做法

新增 `isar_fit_tip_parsimonious`：同时拟合 H1（纯进动，k=5）与 H3（进动+摆动，k=8），摆动只有通过显著性检验才保留：

```
F = ((RSS_H1 − RSS_H3)/3) / (RSS_H3/(n−8))     保留摆动 iff  F > 10
```

同时把 H3 的选种改为"两种排序各取 12 个盆地求并集"：短精修排序（能到 `A=6–10°`）+ 原始残差排序（能到 `A=0.5°`）。这不是按频率分组，而是两个各有盲区的排序互相补盲。

### 11.2 为什么用 F 检验而不是固定百分比

孪生解用 3 个多余自由度去拟合噪声，在 `α=0.5–1°` 上把 RSS 压低了 **8–35%**，任何 2% 的固定容差都拦不住。F 检验能：

| 场景 | RSS_H1/RSS_H3 | F | 判决 |
|---|---|---:|---|
| 纯进动 + 孪生解（α=0.5°） | 1.08–1.35 | **1.1–4.9** | 判 H1，A=0 |
| 真摆动 A=0.5° | — | 758–1104 | 保留 H3 |
| 真摆动 A=3°，fw=1.6 | — | 6.0e4–8.4e4 | 保留 H3 |
| 真摆动 A=6° | — | 1.1e5–1.5e5 | 保留 H3 |
| `fw=fp` 退化 | ≤1 | <1 | 判 H1（诚实拒绝） |

### 11.3 灵敏度窗口变化（v3 → v10，同一噪声序列）

| 参数 | v3 | v10 | 变化 |
|---|---|---|---|
| `fp` | 0.3 – 3.5 Hz | 0.3 – 3.5 Hz | 不变 |
| `alpha` | 0.5 – 12° | **0.03 – 12°** | 下界降一个半数量级 |
| `A` | 0.5 – 3° | **0.3 – 10°** | 上界扩到 10° |
| `fw` | 0.5 – 3 Hz | 0.5 – 3 Hz | 不变 |
| 孔径 | 无（4 个点都在 0.8） | **2 – 5 s** | 打开 |
| `fs` | 0.2 – 4 Hz | 0.2 – 4 Hz | 逐位不变 |

逐点改善：`α` 在 0.03/0.05/0.1/0.2/0.3/1 全部由 0–0.8 变成 1.0；`A` 在 0.2/0.3/6/10 改善；孔径 1/2/3/5 s 全部改善。唯一退步是 `A=0.5°`（1.0 → 0.8，五次里丢一次）。

### 11.4 需要注意的解释边界

- `α=0.03°` 的"成功"用的是判据里 `max(0.2·α, 0.05°)` 的**绝对容差**，即"估计值误差小于 0.05°"，不是 20% 相对精度。该点的实测估计是 0.030–0.038°，确实准，但不要读成"0.03° 也能做 20% 精度"。
- 孔径扫描此前一直有 1 例失败（该组用 `α=1°`），v10 通过简约判决把这一例救回，因此四个孔径点都 ≥0.8、窗口显示为 2–5 s。
- `fw=fp` 现在会被明确判为"无可靠摆动"，而不是给出一个任意摆幅。这是正确的行为：该几何下摆动与进动不可分。

## 12. 判决统一、死配置清理、自旋严格上界、真链路复核（v11）

### 12.1 一条判决路径取代两套（对应遗留项 7）

之前并存两套模式判决：识别实验用"BIC + 0.2° 幅值门限"在 H0–H3 间选，而 `isar_fit_tip_parsimonious` 只做 H1/H3 的 F 检验。现在统一为 `isar_identify_tip_mode`，用同一条嵌套 F 阶梯：

```
H0 静止            k=2
H1 纯进动          k=5
H2 纯摆动          k=5
H3 进动+摆动       k=8

F1 = ((RSS0 − RSS1)/3) / (RSS1/(n−5))     进动是否成立
F2 = ((RSS0 − RSS2)/3) / (RSS2/(n−5))     纯摆动是否成立
F3 = ((RSS1 − RSS3)/3) / (RSS3/(n−8))     在进动之上摆动是否成立
```

任一项 `F > parsimonyF = 10` 即接受。结构判定：进动+摆动→H3；仅进动→H1；仅摆动→H2；都不成立→H0。`isar_fit_tip_parsimonious` 变成它的薄封装，现有调用方无需改动。BIC 与 0.2° 幅值门限不再是判决依据（BIC 仍写入表格作为诊断）。

v11 的 tip 窗口与 v10 完全一致（α 0.03–12°、A 0.3–10°、fp 0.3–3.5 Hz、fw 0.5–3 Hz、孔径 2–5 s），说明统一没有改变判决结果，只是把两套逻辑合并成一套。

### 12.2 死配置清理（对应遗留项 9）

### 12.6 勘误：窗口的读法与 F 的含义（v12）

§1 与 §12 的窗口表按"通过点集的最小值和最大值"书写，这在通过与否非单调时会误导。另外扫描的成功判据此前仍按旧的 0.2° 幅值门限打分，与算法内部按 F 判决不一致，导致低幅度的正确检出被记成失败。两处都已修正，下表为 v12 的权威结果，§1 的表格作废。

| 参数 | 通过（P≥0.9）的点 | 未通过 | 备注 |
|---|---|---|---|
| `fp` | 0.3 0.5 1 2 3.5 Hz | 0.05 0.1 0.2 / 5 7 | 搜索下界已设为 0.30 Hz；此实验无法单独识别孔径的贡献 |
| `alpha` | 0.03 – 12°（全部） | — | 连续 |
| `A` | 0.1 0.2 0.3 **1 3 6 10**° | 0.02 0.05 / **0.5** | **非单调**：0.5° 为 4/5 |
| `fw` | 0.5 0.7 1 2 3 Hz | 0.05 0.1 0.2 / 5 | 连续 |
| 孔径 | 2 3 5 s | 1 s | — |
| `fs` | 历史重复种子扫描 0.2 – 2.0 Hz | 0.05 0.1 / ≥3 | 独立复测中 0.2 Hz 为 3/5，见首页 |

`A=0.5°` 的漏检是**搜索覆盖**问题，不是灵敏度极限：失败那一次选中的 H1 残差是 1.44 Hz，而成功时是 0.17 Hz；F3≈0 说明 H3 根本没找到该盆地（否则残差降 55 倍、F 会是约 750）。同理 `A=0.1°` 5/5 通过、`A=0.5°` 4/5，并不是"越大幅度越难"，而是盆地覆盖随噪声实现波动。修法是把 v3 的 fw 分组也并入池子（三池并集）。

**F 的读法。** 对 H1→H3（多 3 个参数、n=50、df=42）：

```
F = (ΔRSS/3)/(RSS_H3/42) = 14 × (RSS_H1/RSS_H3 − 1)
```

所以 F 不是概率，而是"每多一个自由参数，残差方差降下来的量相当于残差方差本身的几倍"：

| F | RSS_H1/RSS_H3 | 含义 |
|---:|---:|---|
| 1 | 1.07 | 摆动只解释 7% 残差能量（典型孪生解） |
| 10 | 1.71 | 门限：摆动必须砍掉 41% 的残差能量才保留 |
| 126 | 10.0 | `A=0.2°` 实测 |
| 769 | 55.9 | `A=0.5°` 实测 |
| 1.1e5 | 7.9e3 | `A=6°` 实测 |

零幅值时新增分量的频率与相位不可辨识。F 为经验评分，固定阈值的假阳性率尚未标定。历史样本出现负 F，意味着数值搜索得到的较大模型 RSS 高于可嵌入的小模型。

### 12.7 第四个检验 F₄：修正纯摆动场景的模式标签（v13）

§12.1 的判决阶梯漏了一种情形：**纯摆动场景会被标成「进动+摆动」**。

原因是摆动的锥尖多普勒不是纯单音（含 f_w 与 2f_w 分量），而 H₁ 的进动项是一个单音，可以放在 f_p = f_w 处顶替摆动的基波。于是 H₁ 把 RSS 从 20050 压到 37.5，F₁ = 8012 越过门限 → 进入「进动成立」分支；又因 F₃ = 336 > 10 而选了 H₃。

实测（α=0、A=5°、f_w=1 Hz）：

```
H2:  α = 0.000°,  A = 5.006°,  f_w = 1.000,  rms 0.183
H3:  α = 0.004°,  A = 5.005°,  f_w = 1.000,  rms 0.173
```

参数其实是对的（α≈0），错的是模式标签。

**修法**：加一个反向检验，问「在摆动已在场时，进动是否还值那 3 个参数」

$$
F_4=\frac{\left(\mathrm{RSS}_{H_2}-\mathrm{RSS}_{H_3}\right)/3}{\mathrm{RSS}_{H_3}/(N-8)}
$$

并插入一条**降级闸门**（不动其余分支）：

```
若 (N ≥ 18 且 F3 > 10 且 F4 ≤ 10) → H2
否则沿用原判决阶梯
```

之所以只做「降级」而不是改成完全对称的判据：实测发现若只按 F₃/F₄ 判，**小锥角纯进动（α=1°）会被判成静止**——此时 F₃=1.0、F₄=3.9 都不显著，但轨迹其实是一个 11 Hz 的小单音（既能被进动解释、也能被摆动解释）。判断「有没有运动」仍必须靠 F₁。

**回归核对**（7 类场景，`rng(1001)`）：

| 场景 | F₃ | F₄ | F₁ | 输出 | 期望 |
|---|---:|---:|---:|---|---|
| 纯进动 α=1° | 1.0 | 3.9 | 20858 | 进动 | ✓ |
| 纯进动 α=8° | 1.1 | 6316 | 1.32e6 | 进动 | ✓ |
| 进动+小摆 α=3° A=1° | 3742 | 3885 | 774 | 进动+摆动 | ✓ |
| 进动+大摆 α=3° A=6° | 130474 | 130615 | 22.3 | 进动+摆动 | ✓ |
| **纯摆动 α=0 A=5°** | 336.8 | **1.6** | 8012 | **摆动** | ✓（修正） |
| **纯摆动 α=0 A=3°** | 42.9 | **2.3** | 18635 | **摆动** | ✓（修正） |
| 静止 | 0.8 | 0.8 | 3.1 | 静止 | ✓ |

**代价**：H₂ 与 H₃ 本来就是无条件拟的，F₄ 只是两个已有 RSS 的比值，时延增量在纳秒级（相对单次识别 1–3 s 可忽略）。

**测试**：`test_isar_tip_motion_mode_identification` 新增第 5 项，用 α=0、A=5° 的纯摆动轨迹断言 `mode == "swing"` 且 A 误差 < 0.2°，把这一格锁住。

**影响范围**：闸门依据拟合所得 F3、F4 和帧数决定。弱进动或搜索误差可能触发降级。

**自由度保护**：第一版闸门在 1 s 孔径（n=10 帧）上误触发——此时 F₄ 仅有两个名义残差自由度，统计量散布很大，一次真实 α=1° 的进动被判成纯摆动（α 报 0）。因此闸门增加 `n − 8 ≥ 10` 的条件，孔径不足时不启用。加保护后 v14 扫描与 v12 **逐点完全一致**（250 行 × 6 列零差异），窗口不变。

此前该漏洞未被发现，是因为扫描里没有 α=0 的场景。
